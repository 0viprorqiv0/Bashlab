Tạo một sandbox root ảo trên server. Trong sandbox có các thư mục hệ thống cơ bản như /bin, /etc, /usr ở chế độ read-only. Tất cả user dùng chung một role ứng dụng là student, nghĩa là có cùng loại quyền học shell cơ bản. Tuy nhiên, ở tầng hệ điều hành/sandbox, mỗi user vẫn được map sang một UID riêng để tách biệt file và process. Mỗi user sau khi đăng nhập được cấp một workspace riêng trong /tmp, đặt theo database ID, ví dụ user có ID 2193 thì workspace là /tmp/u-2193. User chỉ được đọc/ghi trong workspace của mình, không truy cập được workspace người khác, không sửa được system folder, không kill hoặc can thiệp process của user khác, và không chạm được host thật. Cron job định kỳ dọn các workspace không hoạt động; nếu workspace bị xóa, backend sẽ tạo lại khi user khởi động shell.
