# BashLab Backend

Express 5 API + Shared Docker Runner (`bashlab-box`) + Bubblewrap (`bwrap`) isolation engine.

## Hướng dẫn chạy và vận hành
Xem chi tiết tại: [RUNNING.md](RUNNING.md)

- Khởi động Runner container: `npm run runner:start`
- Khởi động API server: `npm start`
- Chạy unit tests (10/10): `npm test`
- Chạy đo tải benchmark: `npm run benchmark`
- Xem báo cáo terminal dashboard: `npm run report`
